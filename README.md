## Como baixar o projeto

### Pré-requisito

Ter o Git instalado no computador.

### Passo a passo

1. Abra o terminal na pasta onde deseja guardar o projeto.
2. Clone o repositório:

   ```bash
   git clone https://github.com/USUARIO-A/projeto-equipe.git
   ```
3. Entre na pasta criada:

   ```bash
   cd projeto-equipe
   ```
4. Abra o arquivo `README.md` em um editor de texto para consultar ou editar a documentação. (Claro)
